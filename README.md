# PIW — Mapa Simplificado

UserScript para o jogo [Poke Idle World](https://poke.idleworld.online/play) que substitui o mapa gráfico por uma lista simplificada de hunts, com filtros, favoritos e teleporte.

## Instalação

1. Instale o [Tampermonkey](https://www.tampermonkey.net/) no seu navegador.
2. Clique no link abaixo para instalar o script:
   - **[Instalar PIW — Mapa Simplificado](https://raw.githubusercontent.com/SEU_USUARIO/PIW-QOL/main/piw-mapa.user.js)**
3. O Tampermonkey vai abrir uma aba de instalação. Clique em **Instalar**.
4. Abra `https://poke.idleworld.online/play` e recarregue.

## Recursos

- Lista simplificada de hunts (nome, nível, tipo, efetividade, preço, XP)
- Filtros por tipo, acesso e ordenação
- Favoritos (★) e última hunt
- Teleporte ao clicar na hunt
- Aba "Cidades" ao lado das regiões (Kanto / Outland / Orre / Nightmare)
- Botão flutuante de teleporte (favorita / última)
